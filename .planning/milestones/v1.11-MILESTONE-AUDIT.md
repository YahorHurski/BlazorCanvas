# Milestone v1.11 Audit — Storage model rewrite (anchor + geometry JSON)

**Audited:** 2026-07-24

## Definition of Done

v1.11 replaces the four-integer bounding-box storage (`x1,y1,x2,y2`, D-22) with the extensible
**anchor (`x,y`) + `geometry jsonb`** model (D-59). Every existing figure is preserved via a tested
data migration; the canvas-edge clamp is removed. It adds **no new user-facing feature** — a database
model change plus the downstream code churn it forces.
